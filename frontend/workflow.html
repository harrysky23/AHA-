오늘 막힌 개념, 직접 움직여 볼까요?

자료를 올리고, 질문을 적고, 나에게 맞는 학습 방식을 골라요.

  1. 01 자료 업로드
  2. 02 개념·질문 입력
  3. 03 방식 선택
  4. 04 학습 시작

1 내 학습 자료 선택

자료 없이 질문만 입력해도 괜찮아요.

텍스트 PDF는 최대 20쪽·12,000자를 추출해요. 이미지·스캔본 OCR은 지원하지 않아요. Gemini 모드에서는 안내 확인 후 질문·추출 텍스트를 Google에 전송할 수 있어요. 원본 파일은 보관하지 않으며, 생성 명세는 같은 입력의 재사용을 위해 서버 메모리에 잠시 캐시해요.

2 어디가 어려웠나요?

개념이나 질문 중 하나를 입력해 주세요. 수학 II 미분계수·할선→접선 질문을 우선 지원해요.

3 어떻게 배우고 싶나요?

학습 방식
이번에는 이 개념을 배워요

수학 II · f(x) = x²에서 점 P(1, 1)의 미분계수
할선의 기울기 2+h → 접선의 기울기 2

mock은 고정 예제, Gemini는 실제 모델로 설명을 구성해요. Elice는 향후 연결 예정이에요.
