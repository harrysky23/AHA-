- 사회 그래프는 수요·공급 슬라이더와 흉년·풍년·건강식·초기화 시나리오 버튼을 사용합니다.

## 구현 선택

- 프레임워크를 추가하지 않고 기존 vanilla HTML/CSS/JS와 FastAPI를 사용했습니다.
- `references`는 보존하고 실행본만 별도 구성했습니다. 두 MP4는 Base64를 디코딩한 결과와 바이트 단위로 동일합니다.
- 새 학습 폼은 기존 데모 다음에 추가하고 시작 버튼을 연결했습니다. 입력 필드와 결과의 현재 범위를 명시했습니다.
- API는 입력 원문과 파일 메타데이터를 돌려주지만 학습 내용은 항상 동일한 예제입니다. 업로드 내용에 근거했다는 주장을 하지 않습니다.
- 새 수학 뷰어는 별도 문서이며 양·음 h 및 h=0을 구분합니다. `2+h`와 기울기 차이 `|h|`를 사용해 0으로 나누지 않습니다.
- 기존 영상은 1280×720, 약 80.43초입니다. 기획된 새 9:16·30–60초 영상의 구현으로 간주하지 않습니다.

## 검증 한계

- 자동 테스트는 알려진 고정 시나리오만 대상으로 합니다. 임의 수학 문제의 정확성 검증은 없습니다.
- 파일 테스트는 업로드 경계와 헤더 검사입니다. PDF 파서·이미지 디코더·악성 파일 검사 테스트가 아닙니다.
- 브라우저 검증은 설치된 Chrome에서 수행했습니다. Safari·Firefox·실제 휴대전화·부하 테스트는 수행하지 않았습니다.
- Starlette TestClient가 현재 `httpx`에 대해 deprecation 경고를 출력합니다. 테스트는 통과하며, 앱 동작 오류는 아닙니다.
- 운영 인증·사용자 저장소·실행 중단 예산·외부 AI·실제 영상 생성은 후속 범위입니다.
